# FretMaster 🎸

A structured guitar technique learning platform built with React. Master guitar from fretboard fundamentals through advanced improvisation with a progressive, curriculum-based approach.

## Features

- **13 Comprehensive Modules** — From fretboard basics to advanced improvisation
- **Progressive Curriculum** — Beginner → Intermediate → Advanced pathway
- **Progress Tracking** — Mark topics and goals complete, track your journey
- **Built-in Metronome** — Practice with adjustable BPM and time signatures
- **Practice Routines** — Pre-built practice sessions for focused work
- **Responsive Design** — Works on desktop, tablet, and mobile

## Curriculum Overview

### Foundation (Beginner)
- Fretboard Overview
- Warm Ups & Conditioning
- The CAGED Chord System
- Pentatonic & Blues Scales
- Rhythm Guitar Techniques

### Development (Intermediate)
- Drop 2 & Drop 3 Voicings
- Modes of the Major Scale
- Arpeggios
- Bending & Vibrato
- Picking Exercises & Approaches
- Fingerstyle & Clawhammer

### Mastery (Advanced)
- Harmonic Minor, Melodic Minor & Symmetric Scales
- Improvisational Approaches

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Tech Stack

- React 18
- Vite
- React Router
- Local Storage for progress persistence

## Based On

Curriculum derived from BIMM (British and Irish Modern Music Institute) Guitar Techniques professional education materials.
